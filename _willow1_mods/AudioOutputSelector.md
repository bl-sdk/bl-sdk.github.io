Picks which audio device the game plays through, and switches it while the game is running.

The game keeps the device it started with until you restart it. The one you pick here is used
again every time the game starts.

## Settings

- **Audio Output Device**: the device the game plays through. Pick one, then press Apply.
- **Scan Devices**: reads the device list again.
- **Master Volume**: the volume of everything the game plays, whatever device it is on.
