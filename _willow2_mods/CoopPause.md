Allow all players in a coop session to open the pause menu to fully pause the game until someone closes the menu.

ALL players in the lobby must have this installed and running for it to work.


Installation:
Drop the CoopPause.sdkmod file in Borderlands 2/sdk_mods and enable it with the in game mods menu.
