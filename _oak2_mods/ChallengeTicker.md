UVHM rank progression and bulk challenge completion for Borderlands 4.

**BLImGui tab** (install [BLImGui](https://github.com/juso40/blimgui), default bind Ctrl+F7) plus mods menu and console (`bl4cu_open`, `bl4cu_status`). Browse challenges, tick categories, or run UVHM scripts.

**Back up saves** — changes persist. Host/listen recommended. Does not advance story missions.

Install `challenge_ticker.sdkmod` in `sdk_mods`. GPL-3.0.
