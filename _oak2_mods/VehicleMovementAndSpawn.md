Vehicle handling for Borderlands 4: speed, boost, jump, durability, vault costs, plus a catalog to spawn personal vehicles.

**Mods menu** and console (`vehicle_move_help`, `vehicle_move_apply`). **BLImGui panel** optional — install [BLImGui](https://github.com/juso40/blimgui), bind **Open Vehicle Movement tab** (default Ctrl+Alt+F8). Presets: boost, crawl, floaty, orbit, heavy, drift. Scope: local / all / others.

Install `vehicle_movement.sdkmod` in `sdk_mods`. Tune while in a vehicle; re-run `vehicle_move_apply` after travel if needed.
