Swap your appearance to a BL4 NPC, enemy, boss or Vault Hunter. Preview a character, apply it, or restore your original appearance. Hosts can also select lobby players. Squ1ggs Boosting Tools is not required.

Use the SDK Mods menu: type `mods`, select **BL4 Character Swapper**, open its options, then choose **Browse characters**. Categories open into pages of named characters, each with Preview and Apply controls. Player selection, restore, clear-preview and status controls are in the same menu.

Console shortcuts are also available: `bl4cs_list moxxi`, `bl4cs 1` and `bl4cs_restore`. Type `bl4cs_help` for the full list.

**BLImGui is optional and strongly recommended for the searchable F10 picker.** [Installation and downloads](https://bl-sdk.github.io/oak2-mod-db/mods/blimgui/).

Install the [BL4 Python SDK](https://bl-sdk.github.io/oak2-mod-db/), put `bl4_character_swapper.sdkmod` directly in `sdk_mods`, and restart BL4. Enable **BL4 Character Swapper** after loading into a map. Keep only one copy installed.

Character swapping is also included in the Squ1ggs Boosting Tools Appearance tab. Those users do not need this separate mod. If both are installed, disable one and restart.

Not every character has been tested. Characters may keep their idle animations; seating, gun holding and multiplayer visibility need more work. Some entries need DLC or may fail to spawn. Vehicle controls are excluded. Separate character packs are optional; game assets are not bundled with the mod.

[Source code](https://github.com/Squ1ggs/Bl4SDKmods) and [0.2.8 release notes](https://github.com/Squ1ggs/Bl4SDKmods/releases/tag/bl4-character-swapper-v0.2.8).
