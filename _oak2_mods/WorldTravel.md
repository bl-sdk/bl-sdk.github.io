Location bookmarks (quick slots + named saves) and a travel station/map browser for Borderlands 4.

Mods menu or **BLImGui** tab (install [BLImGui](https://github.com/juso40/blimgui), bind **Open World Travel tab**) plus console (`bwt_save`, `bwt_go`, `bwt_help`).

Install `world_travel.sdkmod` in `sdk_mods`. MIT license.
